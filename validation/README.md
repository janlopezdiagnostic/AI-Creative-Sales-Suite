# Validation kit

Everything in this folder exists to get the suite tested by real people selling real creative work, and to record what happens honestly.

- `lean-vs-full-test.md` records the October 2026 bundle test (AI-run, with its limits stated).
- `invite-message.md` is a ready-to-send invitation for a 30-minute test session.
- `observation-checklist.md` is the script for watching a first-time user set the suite up unaided, and for recording exactly where they stall.
- `feedback-questions.md` is the short question set to ask after they have used one skill on a real job.
- `quote-consent.md` is the wording for asking permission to quote someone, and what counts as a yes.

Target: 5 first-time users from creative studios or freelance practices, at least 3 of them non-technical, each completing START-HERE and one real job unaided. The backlog from those sessions outranks any other improvement list for this repo, including this folder.
