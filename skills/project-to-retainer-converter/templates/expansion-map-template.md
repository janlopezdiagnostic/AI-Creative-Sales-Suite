# Expansion Map Template

Use this template between the results recap and the retainer proposal. It maps where ongoing work genuinely exists, route by route, with the evidence for each route stated next to it. A route with no evidence is a hope, not a route: mark it [TO CONFIRM] or delete it. Fill every bracketed field.

## How to read this map
Each row is one expansion route: a direction in which the finished project creates continuing or new work. "Sized in days per month" is an estimate from the evidence in that row, not a promise. Routes the client has not confirmed stay marked [TO CONFIRM] and are excluded from the proposed retainer block until the client confirms them.
