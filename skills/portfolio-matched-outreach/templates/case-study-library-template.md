# Case Study Library

Fill this in once. Keep it current. Every Portfolio-Matched Outreach set matches against this file, and this file alone. A claim that is not in here, with a source and a permission level, does not go in outreach copy. If a field is unknown, write "unknown" rather than leaving it blank: a blank reads as an oversight, "unknown" reads as a fact.

Rules for the whole library:

- One entry per project. Give each entry a short ID (for example CS-01) so outreach drafts can cite it as [CASE STUDY: CS-01].
- Permission is per entry, not per client. A client who allowed a named deck mention may not have allowed a named email mention; if in doubt, downgrade the level and note why.
- Outcomes are recorded exactly as the source states them. No rounding up, no combining two projects into one result, no converting "the client was pleased" into a number.
- An entry whose outcome has no source is still useful for format and category proof, but its outcome line stays out of copy, or appears only as [TO CONFIRM].

## Filled example (all names fictional)

### [CS-07] Project name: Pantry staples range redesign

- **Client:** Verdant Snacks (fictional brand, used here as an example)
- **Permission level for citing:** Anonymised only
  - Permission source and date: Email from the fictional client's brand director, 2026-03-14, permitting anonymised description and shelf photos with branding cropped out.
- **Category:** CPG food packaging
- **Format and deliverables:** Range redesign, 18 SKUs, range architecture, artwork, production support. Repro handled by the client's printer.
- **Buyer type who bought it:** Brand director
- **The trigger or problem:** A retailer range review exposed weak shelf blocking: shoppers could not tell the tiers apart at shelf distance.
- **What the studio did:** Rebuilt the tiering system (good, better, best), redesigned the structural colour blocking, and art-worked all 18 SKUs to the retailer's artwork deadline.
- **Outcome and its source:** Client-reported and permitted: the range kept its full listing at the review. No sales figure was shared or permitted.
  - Outcome wording approved for copy: "kept its full listing through a retailer range review" (anonymised only, no client name, no numbers).
- **Assets available:** Shelf photos (branding cropped), before and after pack shots (anonymised versions only). Stored in the studio portfolio folder.
- **Date completed:** February 2026
- **What this entry can be used to claim:** Range architecture and tiering work at mid-size SKU counts; delivery to a fixed retailer artwork deadline.
- **What this entry cannot be used to claim:** Any sales, share, or revenue outcome; any named-client endorsement; sustainability outcomes (no material change was part of this project).
- **Notes:** Never name Verdant Snacks (fictional) in copy for this entry. If a target competes directly with this client, check the conflict rule before using even the anonymised version.
